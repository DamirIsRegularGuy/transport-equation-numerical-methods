## Содержание ВКР

### Глава 1. Аналитическое решение
- Общая формула решения через метод характеристик
- 4 случая коэффициента переноса `a(x,t)`:
  - Постоянная скорость (`a = const`)
  - Зависящая от координаты (`a = a(x)`)
  - Зависящая от времени (`a = a(t)`)
  - Нестационарная (`a(x,t) = x - t`)

### Глава 2. Аппроксимация разностными схемами

**Явные схемы:**
- Схема «против потока» (Upwind)
- Лакса–Фридрихса
- Лакса–Вендроффа
- TVD / MUSCL

**Неявные схемы:**
- Неявная против потока
- Кранка–Николсона
- Лакса–Вендроффа (неявная)

**Анализ:**
- Нормы ошибок (L1, L2, L∞)
- Устойчивость, численная диффузия, дисперсия, монотонность
- Сравнительный анализ явных и неявных схем
- Рекомендации по выбору схем в зависимости от задачи

## Программный комплекс FluxLab

**FluxLab** — интерактивная «цифровая лаборатория» для исследования уравнения переноса.

### Возможности
- Визуализация решений в виде анимаций
- Сравнение нескольких схем одновременно
- Расчёт и анализ норм ошибок
- Поддержка всех 4 типов коэффициента переноса
- Возможность задания **пользовательских схем** через JSON (без перекомпиляции)
- Интерактивные графики (Plotly)

### Технологии
- **Python** + **PyQt5** (интерфейс)
- **NumPy / SciPy** — вычисления
- **SymPy** — парсинг формул схем
- **Plotly** — графики и анимации
